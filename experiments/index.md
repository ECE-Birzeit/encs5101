# Experiment Navigator

Each guide replaces the matching chapter of the [department manual](/ENCS5101-Manual.pdf){target="_blank"}. It keeps what you need in the lab and drops the rest. Linked experiments are ready; the rest are coming soon. Set up the tools in the [Setup Guide](/setup/) before your first lab.

| No. | Experiment | Topics |
| :-: | --- | --- |
| 1 | [ARM Assembly and Keil uVision5](./exp1-arm-basics) | Program skeleton, core registers and flags, data-processing and load/store instructions, the Keil simulator |
| 2 | [Flow Control Instructions](./exp2-flow-control) | `CMP` and condition codes, branches and loops, `IT` blocks, byte strings and arrays |
| 3 | [Introduction to Microcontrollers and Arduino](./exp3-arduino-intro) | Arduino Mega 2560, sketches, LEDs, push buttons and pull resistors, edge detection, `millis()` timing, keypad and Serial Monitor |
| 4 | DC Motor Control | Reading switches and sensors, software and hardware timing, PWM speed and direction control |
| 5 | Assembly Programming on Arduino | ATmega2560 architecture and addressing modes, port mapping, AVR assembly |
| 6 | Registers, Timers, Interrupts and ADC | Port and timer registers, hardware and software interrupts, ADC with an LDR and a TMP36, 7-segment display |
| 7 | Serial Communication | UART, SPI and I²C, two Arduinos talking, an I²C LCD |
| 8 | LabVIEW with Arduino | LabVIEW basics, the LINX toolkit, controlling an Arduino from a VI |
| 9 | Elevator Control System | The MDA-007 elevator kit: DC motor, photo-interrupter position sensing, limit switches |
| 10 | Introduction to Raspberry Pi | Linux on a single-board computer, GPIO from Python |

::: info
Lab work is graded by your TA during the session. The **Lab work** section at the end of each guide is the work you hand in, not a worked solution.
:::

## How each guide is laid out

- **Objectives**: what you can do by the end.
- **Background**: only the theory the lab work actually uses, with a quick-reference table you can keep open.
- **Examples**: complete programs to build and step through. Predict each result before you run it.
- **Lab work**: the hand-in tasks, with hints.
- **Common problems**: the mistakes everyone makes once.
